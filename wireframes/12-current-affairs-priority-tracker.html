Our model evaluates every shortlisted monthly current affairs theme against 8 calibrated parameters (each scored 0 = absent, 1 = partial, 2 = strong). The weighted sum produces a Priority Index (0–100), which is calibrated through a logistic probability curve to estimate P(asked in Mains 2027).

// THE 8 SCORING PARAMETERS & WEIGHTS (SUM = 100%):
🎯 1. PYQ Recurrence 26% WEIGHT

Strongest predictor: Has the same theme or a close variant been asked in Mains over the last 8–10 years? UPSC frequently re-tests foundational themes under contemporary framing.

0 = Absent | 1 = Partial variant | 2 = High recurrence in PYQ Vault
🇮🇳 2. Govt Priority & India's Stake 14% WEIGHT

Themes at the core of national strategy: Viksit Bharat 2047 pillars, national security doctrines, critical technologies, and major socioeconomic schemes.

0 = Low stake | 1 = Moderate priority | 2 = Top national strategic priority
⏳ 3. Persistence 14% WEIGHT

Structural issues that remain active in the news over months/years versus single-day flash events. Ongoing debates give paper setters adequate time to frame questions.

0 = One-off event | 1 = Active for weeks | 2 = Structural & recurring over months
🏛 4. Institutional / Legal Footprint 12% WEIGHT

Enacted Acts, Supreme Court constitutional bench rulings, official committee reports, or regulatory rules that supply concrete factual substance for question stems.

0 = No formal anchor | 1 = Policy draft/debate | 2 = New Act, SC verdict, or official report
🌐 5. Multidimensionality 10% WEIGHT

Does the topic span multiple dimensions (social, economic, political, environmental, ethical, technological, security)? Themes with 4+ angles allow cross-paper framing.

0 = Narrow single angle | 1 = 2-3 angles | 2 = 4+ distinct angles
⚖ 6. Contestability 10% WEIGHT

Genuine two-sided debate suitable for directive words like 'Critically examine', 'Evaluate', or 'Discuss', requiring balanced arguments from the candidate.

0 = One-sided consensus | 1 = Mild differences | 2 = Sharp, balanced policy debate
📌 7. Syllabus Anchor 8% WEIGHT

Direct mapping to an explicit heading in the official UPSC GS syllabus, ensuring alignment with the prescribed syllabus framework.

0 = Fringes of syllabus | 1 = Implicit link | 2 = Direct mapping to syllabus line
📊 8. Usable Evidence 6% WEIGHT

Concrete statistical indices, committee recommendations, official survey findings, case studies, or constitutional articles ready to quote in answer writing.

0 = Opinion only | 1 = General statistics | 2 = Concrete data, reports & articles
// HOW THE PROBABILITY MODEL CALCULATES PRIORITY
Priority Index (0–100) = Σ(Score / 2 × Weight) × 100

• Objective Weighted Sum: Calculated directly from the 8 parameters (each rated 0–2) multiplied by their respective weights (sum = 100%).
• Logistic Calibration: Converts the index to an estimated probability P(asked) using a logistic curve (Index 50 → 18%, Index 75 → 50%, Index 100 → 82%).

In UPSC Mains, current affairs issues are thematic dossiers, not isolated daily news flashes. When an existing theme has a major new judgment, statute, or committee report in subsequent months:

  • Single Master Dossier: We do NOT create duplicate cards. The original topic card is updated in place.

  • Delta Update Alert: The card gets an orange ⚡ NEW UPDATE [MONTH] callout. If you've already completed the topic, you only need to review the 2-bullet update instead of re-reading foundational notes!
